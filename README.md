8-Bit Arithmetic Logic Unit (ALU) Using Verilog HDL

Overview

This project implements an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU performs arithmetic and logical operations based on a control signal.

The project focuses on digital logic design and functional verification through simulation.

Tools Used

Verilog HDL

ModelSim

ALU Design

The ALU accepts two 8-bit operands and a control input that selects the operation to be performed.

Simulation and Testing

The ALU is simulated using ModelSim to observe the output behavior for different input values and operation selections.
